# Exotics Design System v4

## Identity
**Gaming Media × Cinematic Universe**

## Visual language
- Black / charcoal base
- Neon yellow accent
- Cinematic imagery
- Tactical HUD details
- Angular / industrial framing
- Controlled motion
- Avoid generic RGB-cyberpunk overload

## Components
- Section marker
- HUD label
- News card
- Review card
- Guide card
- Game card
- Article header
- Related content
- CTA
- Ad slot
- Community faction card

All future sections should reuse these patterns rather than inventing unrelated visual styles.
