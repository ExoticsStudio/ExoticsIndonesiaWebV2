# Living System UI

Exotics v4.3 shifts the interface from decorative futurism to a lightweight “living system” metaphor. The HUD, signal ticker, route transition, database scan, command search, game-universe hover state, and mission progress bar are all client-side presentation systems.

Editorial truth remains separate: no fake live data is written to Google Sheets. Any signal that later represents real content should be fed by the read-only JSON cache / sync worker architecture.

The developer Easter egg is triggered by typing `EXO` outside text fields.
