# Article Sharing

Each dedicated article page includes:

- Native share button using the browser share sheet when supported.
- WhatsApp share.
- Facebook share.
- X share.
- Copy article URL.
- Ready-to-copy Exotics Indonesia promotional embed text.

Promotional copy:

Baca artikel gaming selengkapnya di Exotics Indonesia — Gaming Media × Cinematic Universe. News, Review, Game Guide, Featured Content, Community, Merch & Store.

The article URL is injected dynamically, so the shared link always points to the current `/news/{slug}` page.
